### Installation
1. Download the [latest release](https://github.com/sambow23/hdri_cube/releases/latest), extract the `garrysmod` and `rtx-remix` folders inside the archive to your `GarrysModRTX` installation directory.
2. Open the game and load into a map, open the context menu (hold the C key) and select `HDRI Editor` in the top left of the screen
3. Select one of the 8 presets to spawn a HDRI skydome
